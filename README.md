# RoleReady AI

RoleReady AI is a browser-based student career project studio. It compares a student profile with a target job description, maps role-fit signals, identifies missing evidence, and generates a portfolio project brief, sprint plan, resume bullets, and a short Handshake pitch.

## Why this project works for an AI showcase

- It solves a real student problem: turning experience into proof for a specific role.
- It uses an explainable AI-style workflow instead of a black box.
- It creates a finished artifact a recruiter can understand quickly.
- It shows product thinking, frontend craft, data modeling, and prompt-style generation.

## How to run

Open `index.html` in any modern browser. No account, install step, or API key is required.

## Demo flow

1. Click **Sample**.
2. Change the target role or paste a real job description.
3. Click **Analyze fit**.
4. Review the match score, signal map, project brief, skill gaps, sprint plan, resume bullets, and Handshake pitch.
5. Use **Copy** or **Export** to save the generated plan.

## What I built

- A role evidence analyzer across AI, data, frontend, backend, product, and communication categories.
- A visual signal map rendered in canvas.
- A project brief generator that turns gaps into a concrete portfolio build.
- A sprint planner that adapts to 7-day, 14-day, or 30-day timelines.
- Copy and export flows for using the generated content outside the app.
- Local saving through the browser so inputs persist across refreshes.
