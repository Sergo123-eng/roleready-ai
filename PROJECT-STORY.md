# Project Story

## Name

RoleReady AI

## One-liner

RoleReady AI helps students turn a target job description and their existing experience into a recruiter-ready project plan.

## Problem

Students often have relevant experience, but it is scattered across class projects, clubs, internships, and personal builds. When they apply to a role, they need to show evidence for the exact skills in that job post. Most students do not have a fast way to translate their background into a focused project that closes the biggest gaps.

## Solution

RoleReady AI compares a student profile with a job description and produces:

- A match score.
- A visual skill signal map.
- The strongest existing signal.
- The biggest gap to close.
- A portfolio project brief.
- A sprint plan.
- Resume bullets.
- A Handshake profile pitch.

## AI angle

The app uses an explainable AI-style rubric. Instead of hiding the reasoning, it shows the categories and evidence that drive each recommendation. The next version could connect to a language model for richer writing, but the current version is intentionally transparent and demo-ready without accounts or keys.

## Built with Codex

This project was created with Codex as a coding partner. Codex helped shape the product idea, build the interface, implement the analyzer, and package the project story for a student AI showcase.

## Demo script

1. Open the app and load the sample.
2. Explain that the left side represents a student profile and job post.
3. Click Analyze fit.
4. Point to the match score and signal map.
5. Open the generated project brief and sprint plan.
6. Show the resume bullets and Handshake pitch.
7. Explain how the tool helps a student build proof instead of only editing wording.
